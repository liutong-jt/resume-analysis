### 🚀 智能扫描简历视觉分析系统 - 需求规格说明书 (Rev 2.0)

#### 1\. 系统概述与核心理念

本系统旨在利用最新的多模态视觉大语言模型（VLM），解决传统的OCR+NLP模式在处理格式复杂、排版多样的扫描版简历时的痛点。

**核心理念：**

  * **End-to-End 视觉理解：** 不再进行单独的文字提取步骤。系统将简历（PDF）转换为图像序列，直接输入给 VLM，让 AI 像人眼一样“阅读”简历的布局、文字、图表。
  * **结构化输出驱动：** VLM 的核心任务不仅是理解，更是将非结构化的图像信息转化为严格定义的 JSON 数据结构，以便前端进行排序和筛选。
  * **交互式对比：** 提供原文图像与 AI 分析结果的同屏对照，建立用户对 AI 结果的信任感。

-----

#### 2\. 详细功能需求 (Functional Requirements)

##### 2.1 数据输入与预处理层 (Backend)

  * **批量上传：** 前端支持拖拽上传包含多个 PDF 文件的文件夹。
  * **PDF 转图像服务（关键）：**
      * 由于目前的 VLM API 主要接收图像输入，后端必须包含一个服务，将接收到的 PDF 文件的每一页转换为高质量的图像格式（如 PNG 或 JPEG）。
      * *注意：需处理多页简历的情况，确保同一个人的多张图片作为一个整体发送给 VLM。*

##### 2.2 VLM 核心分析引擎 (AI Layer)

  * **模型接口：** 使用符合 OpenAI Chat Compeletions API 格式的视觉模型接口 (如 GPT-4o, Claude 3.5 Sonnet, 或其他私有化部署的 VLM)。
  * **分析任务 (由 System Prompt 驱动)：**
    1.  **基础信息提取：** 姓名、最高学历、工作年限（从图像中推断）。
    2.  **领域分类（单选）：** 基于简历整体内容，将候选人归类为以下核心方向之一：
          * 大数据 (Big Data)
          * 人工智能 (AI)
          * 云网 (Cloud & Network)
          * 应用开发 (App Development)
          * 其他 (Other)
    3.  **四维评估矩阵（打分+理由）：**
          * 对四个维度进行 1-10 分的量化评估，并给出简短的定性理由。
          * 维度：技术基础、技术认知、技术潜力、学习能力。
    4.  **综合摘要：** 生成一句简短的推荐语（例如：“具有扎实Java基础和丰富电商项目经验的后端开发，潜力中上”）。

##### 2.3 前端交互与展示层 (Frontend)

  * **提示词管理界面：**

      * **标准模式（默认）：** 使用系统内置的、经过优化的 VLM System Prompt（不可见或仅供查看）。
      * **自定义模式（高级）：** 提供文本域，允许用户输入 Ad-hoc 指令。例如用户选择一批简历，输入：“请检查这些简历中是否有提及‘担任 Team Leader’的经历，只回答是或否”。

  * **结果看板 (Dashboard) - 分组与排序：**

      * 界面以 Tab 页形式展示五个领域分组（大数据、AI、云网、应用开发、其他）。
      * 每个 Tab 页内是一个表格/列表。
      * **默认排序：** 列表根据 AI 计算的“综合匹配度总分”自动降序排列，优先展示 Top N。
      * 列表项展示摘要：姓名 | 总分 | 核心领域 | 一句话推荐语。

  * **详情透视 (Split View) - 核心交互亮点：**

      * 用户点击列表中的某位候选人时，弹出一个全屏模态框或跳转到详情页。
      * **左侧视窗 (50%)：** 展示原始简历的图像（支持缩放、多页滚动查看）。
      * **右侧视窗 (50%)：** 展示结构化的 AI 分析报告。
          * 包含：基本信息、领域标签。
          * 核心：四个维度的雷达图或进度条展示分数，下方附带 AI 给出的定性分析理由。

#### 3\. VLM System Prompt 设计 (核心交付物)

这是系统的灵魂。我们需要设计一个强大的 Prompt，迫使 VLM 输出严格的 JSON 格式，并进行深度的推理分析。

**System Prompt 草案：**

````markdown
你是一位拥有20年经验的资深技术招聘专家。你的任务是阅读提供的一份或多份简历图像（属于同一个候选人），进行深度的技术评估，并以严格的 JSON 格式输出结构化报告。

**你的分析步骤如下：**

1.  **全局阅读与基本信息提取**：阅读所有图像，提取候选人姓名（如果找不到用 "Unknown" 代替）。
2.  **领域分类**：判断候选人的主要技术栈和项目经验最契合以下哪个领域，**必须**只选择一个最相关的：['大数据', '人工智能', '云网', '应用开发', '其他']。
3.  **四维深度评估**：基于简历中的教育、项目、实习、技能描述，对以下四个维度进行评估。每个维度给出一个 1-10 的分数（10分最高，例如：精通、有深刻见解、行业领先；1分最低），并提供 30 字以内的简短理由。
    * **技术基础 (tech_foundation)**：考察技术栈与目标领域的匹配度，以及掌握的深度（是仅仅使用过还是理解原理）。
    * **技术认知 (tech_cognition)**：考察项目描述中体现的架构思维、解决复杂问题的思路，而非简单的功能堆砌。
    * **技术潜力 (tech_potential)**：考察是否有创新成果、开源贡献、竞赛获奖，或对前沿技术（如 GenAI, 云原生）的探索。
    * **学习能力 (learning_ability)**：考察技术跨度、成长轨迹、自学经历或跨领域技能。
4.  **一句话总结**：生成一个不超过 50 字的核心优势摘要。

**输出要求（非常重要）：**
* 你**只**被允许输出 JSON 格式的数据，不要包含任何 markdown 标记（如 ```json ... ```）或额外的对话文本。
* 确保输出的 JSON 可以被 Python 的 `json.loads()` 直接解析。

**目标 JSON 结构模版：**
{
  "candidate_name": "姓名",
  "domain_classification": "选择一个领域",
  "summary_one_liner": "一句话摘要",
  "evaluation_matrix": {
    "tech_foundation": { "score": 整数1-10, "reason": "简短理由" },
    "tech_cognition": { "score": 整数1-10, "reason": "简短理由" },
    "tech_potential": { "score": 整数1-10, "reason": "简短理由" },
    "tech_cognition": { "score": 整数1-10, "reason": "简短理由" }
  },
  "total_score": (四个分数的总和，整数)
}
````

#### 4\. 技术栈推荐 (Technical Stack)

  * **前端 (Modern Web):**

      * **框架:** Next.js (React 框架) 或 Vue 3。推荐 Next.js，因为它在构建复杂的企业级 Dashboard 和处理 API 请求方面更有条理。
      * **语言:** TypeScript (强烈推荐，用于确保前后端数据结构的一致性，特别是处理 AI 返回的复杂 JSON 时)。
      * **UI 组件库:** Ant Design (React/Vue 都有) 或 Tailwind CSS + ShadcnUI，用于快速构建专业的表格和侧边栏。
      * **状态管理:** Zustand (React) 或 Pinia (Vue)，用于管理上传队列和分析结果数据。

  * **后端 (API Layer):**

      * **语言:** Python (处理 PDF 和调用 AI 接口的首选) 或 Node.js (NestJS)。
      * **框架:** FastAPI (Python) 或 NestJS (Node.js)。
      * **PDF 转图片库:**
          * Python: `pdf2image` (需要安装 poppler) - 效果最好，最稳定。
          * Node.js: `pdf-poppler` 或类似库。

  * **AI 服务:**

      * 任何提供 OpenAI 兼容接口的 VLM 提供商 (OpenAI GPT-4o/4-turbo, Anthropic Claude 3 via adapter, 或国内支持 VLM 的大模型 API)。

这个重新设计的方案更加现代化，充分利用了 VLM 的能力来简化后端逻辑，并将重心转移到了提供卓越的前端用户体验上。
